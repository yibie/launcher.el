# Templates for `launcher-snippets-tool' (set `launcher-snippets-file' to this file).
# launcher 里输入 "t " 列出全部模板，回车填好占位符并复制到剪贴板，焦点回到原应用后直接 ⌘V。
# 每个有正文的标题是一个模板；只用来分组、下面没有正文的标题会被跳过。
# 正文里不要有以 * 开头的行，那会被当成下一个模板的标题（列表请用 -）。
#
# 自动填，不询问：
#   {clipboard}  {date}  {time}  {datetime}  {day}（星期五）  {uuid}
#   日期时间可加选项：{date offset="+7d"}  {time offset="-2h"}  {date format="%Y/%m/%d"}
#   offset 单位：m 分钟  h 小时  d 天  w 周  M 月  y 年（区分大小写）；format 见 format-time-string
#
# 询问（同一个提示只问一次，按书写顺序问）：
#   {input:提示}                      单行，空白输入框
#   {input:提示|默认文字}             预填，回车接受或先改
#   {input:提示|clipboard}            预填剪贴板；也可写 date、time、date offset="+7d" 等
#   {multi:提示}  {multi:提示|默认}   多行，C-j 换行，回车结束
#   {choice:提示|甲,乙,丙}            从选项里选，默认第一项
#   {optional:提示} ... {/optional}   回答 y 才保留这一段；不能嵌套
#
# 引用其他模板（共享答案）：{snippet:模板名}
#
# 修饰符（按顺序应用，竖线两边要有空格）：{clipboard | trim | uppercase}
#   trim  uppercase  lowercase  capitalize  oneline（合成一行）  quote（每行加 "> "）
#   percent-encode（网址编码）  json-stringify（JSON 字符串）
